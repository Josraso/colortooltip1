🎨 Test del Módulo Color Tooltip (SIMPLE)

Prueba: Pasa el mouse sobre cualquier input de color para ver el tooltip con el nombre.
Consola: Abre la consola (F12) para ver cuántos inputs se detectaron.

Ejemplos de tooltips

Qué hace el módulo

  • ✅ Muestra un tooltip simple con el NOMBRE del atributo de color
  • ✅ NO muestra formatos HEX, RGB, HSL (eso ya lo ves en el selector)
  • ✅ NO tiene historial de colores (innecesario)
  • ✅ NO tiene preview del color (ya lo estás viendo)
  • ✅ Solo un tooltip simple tipo "Rojo pálido", "Azul marino", etc.

Prioridad del texto mostrado

  1. data-color-tooltip - Atributo específico del módulo
  2. data-tooltip - Atributo genérico
  3. title - Atributo HTML estándar
  4. Texto del <label> asociado (por ID o padre)
  5. placeholder - Texto del placeholder
  6. Fallback: "Color"

En PrestaShop

En tu tienda PrestaShop, el módulo detectará automáticamente los selectores de atributos de color.

Si un atributo se llama "Rojo pálido" en tu catálogo, ese nombre aparecerá en el tooltip.

No necesitas hacer nada más, solo instalar el módulo.
