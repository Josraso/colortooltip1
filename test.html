🎨 Test del Módulo Color Tooltip

Estado: Pasa el mouse sobre cualquier input de color para ver el tooltip.
Consola: Abre la consola del navegador (F12) para ver cuántos inputs se detectaron.

Diferentes tipos de inputs de color

Funcionalidades a probar

  • ✅ Hover: Pasa el mouse sobre un input para ver el tooltip
  • ✅ Focus: Haz clic en un input (también mostrará el tooltip)
  • ✅ Cambio de color: Cambia el color de un input y verás que se guarda en el historial
  • ✅ Historial: Cambia varios colores y verás el historial de colores recientes
  • ✅ Click en historial: Haz clic en un color del historial para aplicarlo al input actual
  • ✅ Tema automático: El tooltip cambia de tema (claro/oscuro) según el color
  • ✅ Múltiples formatos: Ver el color en HEX, RGB y HSL

Información técnica

El módulo detecta automáticamente:

  • input[type="color"]
  • .input-color
  • .color-picker
  • input.color
  • [class*="color-input"]

El número de inputs detectados se mostrará en la consola del navegador.
